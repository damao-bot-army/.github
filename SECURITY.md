# Security policy

## Report a vulnerability privately

Please use GitHub Private vulnerability reporting in the affected repository:

1. Open the repository's **Security** tab.
2. Select **Report a vulnerability**.
3. Describe the issue, affected versions, potential impact, and steps to reproduce it. Include a minimal proof of concept when possible, but do not include credentials or personal data.

Do not open a public issue or disclose exploit details in a public pull request.

If **Report a vulnerability** is not available, please do not post the report publicly. A repository maintainer must enable private vulnerability reporting before you can submit it through this channel.

We will respond as soon as possible and coordinate next steps privately.
